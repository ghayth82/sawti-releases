# صوتي (Sawti)

تطبيق لتحويل الكلام إلى نص، يعمل على جهازك دون إنترنت، والعربية لغته الأولى.

## التنزيل

نزّل أحدث إصدار من صفحة **[Releases](https://github.com/ghayth82/sawti-releases/releases/latest)**:

| الملف | النظام |
|---|---|
| `Sawti_..._x64-setup.exe` | Windows 10 / 11 (تثبيت عادي) |
| `Sawti_..._x64-portable.zip` | Windows — نسخة محمولة دون تثبيت |
| `Sawti_..._aarch64.dmg` | Mac (Apple M1 وما بعده) |
| `Sawti_..._x64.dmg` | Mac (Intel) |

**Windows:** إذا ظهرت رسالة «Windows protected your PC» اضغط **More info** ثم **Run anyway**.

**Mac:** بعد نقل التطبيق إلى Applications نفّذ مرة واحدة في Terminal:

```
xattr -cr /Applications/Sawti.app
```
